## 九宫格 3D 表情贴纸

[@BAXSCTO · X 原帖](https://x.com/BAXSCTO/status/2097554076494102704) · [Prompt 原文](https://x.com/BAXSCTO/status/2097554076494102704)

[![九宫格 3D 表情贴纸 · 效果图 1](https://pbs.twimg.com/media/HRwCF0SbsAE5IJP.jpg?name=orig)](https://x.com/BAXSCTO/status/2097554076494102704)

**作者 Prompt 节选**

```text
基于我上传的图片，设计一套 3D 表情包
```

<details>
<summary>中文尝试版 Prompt（项目整理，未复现）</summary>

```text
以我上传的角色图片为参考，制作一张正方形 3D 表情贴纸页。按 3×3 排列九个同一角色，每个使用不同表情、动作或反应，保持角色外形一致。贴纸之间留宽间隔，不要重叠，背景透明。加入庆祝、加油、惊喜等情绪与少量对应小道具。
```

</details>

需要上传角色参考图；这里的图片是作者发布的展示图，实际透明通道需自行检查。

<summary>中文尝试版 Prompt（项目整理，未复现）</summary>

